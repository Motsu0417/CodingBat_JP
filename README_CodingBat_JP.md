## プロジェクト背景

CodingBatはプログラミング基礎の学習に有用ですが、問題文は英語中心です。
本リポジトリは、日本語話者が取り組みやすいように問題文や学習導線を整理することを目的にしています。

## 重要事項

### 非公式プロジェクト

本リポジトリはCodingBatの非公式プロジェクトです。
CodingBatの運営・開発者とは関係ありません。

### 著作権

CodingBatの問題内容および問題構成の著作権は、CodingBatおよびその作者に帰属します。
本リポジトリは学習支援の目的で、日本語化・整理を行っています。

### AI利用

翻訳や説明文の一部にAIを利用しています。
そのため、表現や記述に不正確な点が含まれる可能性があります。
誤りを見つけた場合はIssueまたはPull Requestを歓迎します。

### 免責

本リポジトリのコード実行や利用に伴う影響（障害・データ損失など）について、
本プロジェクトは責任を負いません。
利用は自己責任でお願いします。

## 目的

- 日本語話者がCodingBatに取り組みやすい状態を作る
- Java / Python初学者の演習コストを下げる
- 問題文理解のハードルを下げる

## 想定用途

- Java / Python学習の初期トレーニング
- 授業・自主学習での演習素材
- 基本文法とロジック練習
